## 📱 Экраны
## TabItem (Vehicle) 

### 1. ListVehicleView
- **Что показывает**: список автомобилей (название) + удаление 
- **Элементы**:
  - `CollectionView` (Список авто)
    - Картинка авто, название авто, кнопка удалить
  **Кнопки**:
  - `ImageButton` ("+") 
  - `ImageButton` (image "удалить авто")  
   - `ImageButton` (image "редактировать авто")  
- **Поведение**:
  - Нажатие на Авто → навигация на (CardVehicleView)
  - Нажатие на «+» → навигация на (CreateVehicleView)
  - Нажатие на «удалить» → Команда удаления авто
  - Нажатие на "Редактировать" → Переход на CreateVehicleView 

### 2. CreateVehicleView
- **Что делает**: добавляет новый автомобиль
- **Поля**:
  - Название ТС (Entry | String)
  - Пробег (Entry | int)
  - Дата покупки (Entry | DateTime)
  - Дата производства (Entry | DateTime)
  **Элементы**:
  - `Picker` (Выбор тип ТС "Автомобиль,Мотоцикл,Грузовое Авто" | String)
  - `DatePicker` ( Дата покупки | DateTime )
  - `DatePicker` ( Дата производства | DateTime )
- **Кнопки**:
  - «Сохранить» — активна только если оба поля заполнены
- **Поведение**:
  - При нажатии кнопки Проверка валидации
  - Создание класса ТС и сохранение в Локальную БД
  - После сохранения — автоматический возврат на ListVehicleView
  **Валидация** (RealTime):
  - Пробег
  - Дата покупки не может быть раньше производства

  ### 3. CardVehicleView
- **Что делает**: показывает карточку автомобиля
- **Поля**:
  - Название ТС (Label | String)
  - Пробег (Label | int)
  - Дата покупки (Label | DateOnly)
  - Дата производства (Label | DateOnly)
  - Тип Тс (Label | String)

## TabItem (Repair) 

### 1. ListRepairView
- **Что показывает**: Просмотрт и переход на добавление ремонта
- **Элементы**:
  - `Picker` (Выбор авто для отображения ремонтов)
  - `CollectionView` (Название ремонта,дату ремонта, дата создания ремонта,прогресс бар)
  **Кнопки**:
  - `ImageButton` ("+") 
  - `ImageButton` (image "удалить авто")  
  - `ImageButton` (image "редактировать авто")  
- **Поведение**:
  - Нажатие на Ремонт → навигация на (CardRepairView)
  - Нажатие на «+» → навигация на (CreateRepairView + parament(Vehicle_Id))
  - Нажатие на «удалить» → Команда удаления авто
  - Нажатие на "Редактировать" → Переход на CreateRepairView 


  ### 1. CreateRepairView
- **Что показывает**: добавление новго ремонта ремонта
- **Элементы**:
  - `Picker` (Выбор тип ремонта)
  **Поля**:
  - Интервал замены (Entry | int)
  - Дата ремонта (Entry | DateOnly)
  - Пробег (Entry | int)
  - Запчасти (Entry | String)
  - Стоимость (Entry | int)
  - Описание работ (Entry | String)
  **Кнопки**:
  - `Button` (Создать) 
  **Поведение**:
  - Нажатие на Создать → создание нового ремонта 
 **Валидация**:
- Валидация пробега пробег не может быть меньше чем текущий и обязателен
- Стоимость не може быть отрицательным

 ### 3. CardRepairView
- **Что делает**: показывает карточку автомобиля
- **Поля**:
  - Пробег авто на момент ремонта (Label | String)
  - Дата ремонта (Label | string)
  - Замененные запчасти (Label | string)
  - Стоимость ремонта (Label | string)
  - Описание работ (Label | String)
> Хранение: SQLite локально. Никаких доп. таблиц или связей.
